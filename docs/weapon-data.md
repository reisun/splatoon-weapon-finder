# ブキデータの検証・更新仕様

## 対象と確認日

2026年10月8日確認、Splatoon 3 Ver.11.3.0 の対戦で使用できる全174ブキ（通常160、レプリカ14）。サーモンラン専用・ヒーローモード専用ブキは含めない。

## 出典と照合

- [任天堂 Ver.10.0.0 更新情報](https://support.nintendo.com/jp/switch/software_support/av5ja/1000.html): バンカラコレクション30件の正式名称とサブ・スペシャル。名称の括弧内の読み仮名は収録しない。
- [任天堂 最新の更新情報](https://support.nintendo.com/jp/switch/software_support/av5ja/index.html): Ver.11.3.0、PETシューター レプリカの追加とスプラシューターコラボとの同一性能を確認。
- [Splatoon 3 攻略＆検証Wiki・ブキ](https://wikiwiki.jp/splatoon3mix/ブキ): 全174件の名称、種別、サブ・スペシャルを照合。
- [Game8・サブスペ組み合わせ一覧](https://game8.jp/splatoon3/482035): PET追加前の173件すべてについてWikiと一致。表記揺れ（レプリカの空白、ガロンの先頭ピリオド、ヒューの中点、フルイドのV）を正規化して照合。
- [イカクロ・オクタシューター レプリカ](https://www.ikaclo.jp/3/weapons/352): スプラッシュボム／トリプルトルネードを再確認。

Webデータは実行時に取得せず `src/data/weapons.ts` に静的に保持する。更新時には公式の追加情報と全ブキ一覧を再照合し、この文書の確認日・対応バージョン・件数と画面の表示を更新する。

## 射程の分類

射程5分類はこのアプリ独自の検索用の目安であり、公式の分類ではない。[検証Wiki・射程一覧](https://wikiwiki.jp/splatoon3mix/ブキ/ブキ性能#weapon_range) の試し撃ちライン単位の数値（表はVer.10.1.0時点）を用いる。後続バージョンの実機で全ブキを再測定した値ではない。

| 分類 | 射程（ライン） |
| ---- | -------------- |
| 短   | 2.3以下        |
| 中短 | 2.3超、2.8以下 |
| 中   | 2.8超、3.5以下 |
| 中長 | 3.5超、4.5以下 |
| 長   | 4.5超          |

攻撃方法で射程が変化する場合は長い側を採用する（ローラーのタテ振り、ワイパーのタメ斬り、ボトルの初弾、クーゲルの長射程モード、S-BLASTの地上撃ち、ガエンのスライド前、ケルビンのスライド後）。チャージャーはフルチャージ、ストリンガーはフルチャージの射程。ブラスター・エクス・トライストリンガー・フルイドは爆風、スクリューは渦、ローラー・シェルターはダメージ射程、その他は有効射程を採用する。攻撃特性が異なるので同じ分類でも同じ戦い方を意味しない。

派生ブキ・レプリカは元のメインと同じ分類にする。オーダーブラスターはノヴァ、オーダースピナーはバレル、オーダーワイパーはジム、オーダーブラシはホクサイに対応する。

## 今回の修正記録

旧163件から未登場・前作由来の33件を削除し、未収録44件を追加して174件にした。既存ブキ79件のサブ・スペシャル、46件の射程分類を修正した。スペシャル選択肢はウルトラハンコを追加し、スプラトゥーン2のスーパーチャクチを削除。型からもスーパーチャクチとルール専用のガチホコショットを削除した（選択可能なスペシャルは19種）。

## 検証

Docker環境で `npm test`（lint・formatチェック・ユニットテスト）と `npm run build` を実行する。データテストは総数・種別内訳・名前の重複・フィルタ選択肢の網羅性、および誤っていた構成・追加ブキ・レプリカの代表例を確認する。テストのみではWeb情報の正しさは保証できないため、更新時の外部資料との照合は継続して必要。
